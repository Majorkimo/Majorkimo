AI Artifact Audit reports source-pattern candidates for review. It does not identify AI authorship or replace a complete application audit.

## How I approach tools

- **Solve a specific problem.** Keep the purpose clear and the setup practical.
- **Make behavior inspectable.** Explain what is measured, checked, and left unverified.
- **Test against real work.** Use real codebases alongside regression cases, without pretending a passing test catches everything.
- **Share useful building blocks.** Publish tools people can run, inspect, and improve.

## Ideas and contributions

Found a bug or have a useful idea? Open an issue in the relevant repository. A short reproduction, your environment, and what you expected make it much easier to help.

If a tool helps you, a star makes it easier for other developers to find it.
